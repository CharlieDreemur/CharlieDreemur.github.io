Role: Solo Developer

- Developed an auto chess system for unit placement and automated combat
- Designed a node-based ability system, akin to UE BP, enabling both developers and players to create custom abilities with task nodes
- Used a **Unity DOTS** framework with Job system and Burst compiler to increase performance.
- Implemented an Excel loader to automatically generate table class and ScriptableObject based on configuration

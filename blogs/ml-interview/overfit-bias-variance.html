什么是 overfitting / underfitting？
bias-variance tradeoff 是什么？怎么判断、怎么解决？

英文问法What is overfitting and how do you prevent it? · Explain the bias-variance tradeoff. · How do you tell if a model is overfitting or underfitting?

先弄清楚：每个概念是什么

Overfitting
像死记硬背的学生：练习题全对，换一道题就不会。模型连训练数据里的 noise 也背下来了。 例：10 个点用 9 次多项式，train MSE = 0，test MSE = 0.69。
Underfitting
像只背了一句口诀的学生：练习和考试都不行。模型太简单，train、validation error 都高。 例：用直线拟合 sin 曲线，train 0.34、test 0.33。
Bias
射箭比喻：换很多批训练数据、各训练一次，箭的平均落点离靶心多远。模型假设太死，平均就是偏的。
Variance
同一个比喻里，箭彼此散得多开：换一批训练数据，预测变多少。模型太灵活，就会跟着每批数据的 noise 跑。
Learning curve
train / validation error 随训练样本数变化的曲线。两者之差叫 generalization gap，用来判断问题出在 bias 还是 variance。

30 秒回答

Overfitting means the model fits the training noise: low training error, much higher validation error. Underfitting means it's too simple, so both errors are high. For squared loss, expected test error = bias² + variance + irreducible noise. Bias is how far the average prediction over training sets is from the truth; variance is how much the prediction moves when the training set changes. More capacity lowers bias and raises variance, so overfitting is high variance and underfitting is high bias. To fix overfitting: more data or augmentation, L1/L2 or dropout, early stopping, a smaller model, or bagging. To fix underfitting: a bigger model, better features, less regularization.

推导：bias-variance decomposition

设 \(y = f(x) + \varepsilon\)，\(\operatorname{Var}(\varepsilon) = \sigma^2\)，\(\bar f = \mathbb E_D[\hat f(x)]\) 是换遍训练集的平均预测。把 \(y - \hat f\) 拆成 \((f - \bar f) + (\bar f - \hat f) + \varepsilon\)，平方取期望，交叉项都是 0：

\[ \mathbb E\big[(y - \hat f)^2\big] = \underbrace{(f - \bar f)^2}_{\text{bias}^2} + \underbrace{\mathbb E_D\big[(\hat f - \bar f)^2\big]}_{\text{variance}} + \underbrace{\sigma^2}_{\text{noise}} \]

noise 是任何模型都消不掉的下限。capacity 越大，bias 越小、variance 越大，test error 呈 U 形。

实测：多项式回归

\(\sin 2\pi x\) 加 noise（\(\sigma^2 = 0.09\)），10 个点训练，换 2000 个训练集：

1 次（直线）0.340.330.220.02underfit

每一行都满足 test ≈ bias² + variance + 0.09。

怎么判断是 overfit 还是 underfit

一句话：比较 train error 和 validation error。

  1. train error 离 noise 下限（实际里用人类水平或 baseline）很远 → underfit（high bias）。
  2. train error 低，validation error 高很多 → overfit（high variance）。
  3. 拿不准就画 learning curve：加数据后 gap 持续缩小 → variance，加数据有用；两条线贴在一起、停在高处 → bias，要换更强的模型。

例：上面的实验，训练点数 \(N\) 从 10 加到 100：

9 次：train / test0.00 / 0.690.05 / 0.130.07 / 0.110.08 / 0.10

9 次的 gap 从 0.69 缩到 0.02，加数据治好了 overfit。直线停在 0.29，远高于 0.09，数据加 10 倍也没用，所以这是 underfit。

必答点

  • overfit：train 低、validation 高 → high variance；underfit：两个都高 → high bias
  • test MSE = bias² + variance + noise；capacity 越大，bias ↓、variance ↑
  • 判断：train vs validation error，拿不准就画 learning curve
  • 解决 overfit：more data / augmentation、L1 / L2（见 L1 vs L2）、dropout、early stopping、减 capacity、bagging
  • 解决 underfit：增大 capacity、加 feature、减弱 regularization、训练更久

追问

Regularization 为什么能防 overfitting？

限制 weight 就是限制有效 capacity，用一点 bias 换 variance 大幅下降。上表 \(\lambda = 10^{-4}\) 把 variance 从 0.60 压到 0.04。\(\lambda\) 太大又会 underfit，所以用 cross-validation 选。

Early stopping 为什么也算 regularization？

validation error 开始上升就停，限制了参数离初始值能走多远。线性模型 + squared loss + gradient descent 时，它等价于 L2（Goodfellow §7.8）。

Dropout 为什么能防 overfitting？

训练时随机关掉一部分 unit，相当于训练很多共享参数的子网络再取平均，近似 bagging（Goodfellow §7.12），也避免 unit 之间 co-adaptation。

Bagging 和 boosting 分别降什么？

Bagging 对多个 high-variance 模型（比如深树）取平均，降 variance；boosting 串行地修正前一轮的错误，降 bias（Murphy §18.5）。

参数远多于样本，为什么不一定 overfit？

参数数 \(P > N\) 之后 test error 会再次下降，叫 double descent。模型能用更平滑的函数穿过全部训练点（Murphy §13.5.7）。

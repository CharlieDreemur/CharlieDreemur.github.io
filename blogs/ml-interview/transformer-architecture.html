先弄清楚：每个概念是什么

Encoder 与 decoder
像同声传译：encoder 先把整句原文听完，每个词都能看到所有词（双向）；decoder 逐词说出译文，用 causal mask 只能看自己和前面已经说出的词。例：原版 encoder、decoder 各 6 层，\(d_{\text{model}} = 512\)，8 个 head。
Cross-attention
decoder 里的第二个 attention：Q 来自 decoder，K、V 来自 encoder 的输出。相当于译员边说边回头查原文。
Residual + LayerNorm
每个 sub-layer 的输出加回输入，\(x + F(x)\)：给信号修了一条直达通道，gradient 能直接流回浅层。LayerNorm 再把每个 token 的向量拉回 mean 0、variance 1。
Post-LN 与 pre-LN
LayerNorm 放在 residual 相加之后（post，原版）还是放进分支里、在 \(F\) 之前（pre）。pre-LN 的直达通道上没有 LN，深层训练更稳。
FFN（position-wise）
两层 MLP，对每个 token 单独做、所有位置共享参数。attention 负责 token 之间交换信息，FFN 负责每个 token 自己"消化"。例：512 → 2048 → 512。

30 秒回答

The original Transformer is an encoder-decoder. Each encoder layer has multi-head self-attention and a position-wise feed-forward network, two linear layers with a ReLU and a hidden size of 4·d_model. Every sub-layer is wrapped in a residual connection followed by LayerNorm. The decoder adds two things: its self-attention is causally masked, and a cross-attention sub-layer takes queries from the decoder and keys and values from the encoder output. Positional encodings are added to the input embeddings. Modern LLMs are decoder-only and use pre-LN, normalizing the input of each sub-layer, which keeps gradients stable without warm-up, plus RMSNorm, SwiGLU, RoPE and grouped-query attention.

关键公式

Post-LN vs pre-LN（\(F\) = attention 或 FFN）

\[ \text{post-LN:}\quad x_{l+1} = \mathrm{LN}\big(x_l + F(x_l)\big) \] \[ \text{pre-LN:}\quad x_{l+1} = x_l + F\big(\mathrm{LN}(x_l)\big) \]

pre-LN 在最后一层后再加一个 LN。post-LN 初始化时靠近输出层的 gradient 很大，要靠 learning-rate warm-up；pre-LN 的 gradient 被 \(1/\sqrt{L}\) 压住，可以去掉 warm-up。GPT-2 已经用 pre-LN。

FFN 与 cross-attention

\[ \mathrm{FFN}(x) = \max(0,\, xW_1 + b_1)\,W_2 + b_2 \] \[ \mathrm{Cross}(H_{\text{dec}}, H_{\text{enc}}) = \mathrm{softmax}\Big(\frac{QK^\top}{\sqrt{d_k}}\Big)V \]

\(W_1\)：\(d\times 4d\)，\(W_2\)：\(4d\times d\)。cross-attention 里 \(Q = H_{\text{dec}}W_Q\)，\(K, V\) 由 \(H_{\text{enc}}\) 投影得到。

Parameter count：每层 ≈ \(12d^2\)（attention \(4d^2\) + FFN \(8d^2\)），decoder 层多一个 cross-attention，是 \(16d^2\)。怎么算见 Transformer 复杂度速查。

原版 vs 现代 LLM

原版 Transformer（2017）现代 decoder-only LLM
结构encoder-decoder只有 decoder（causal mask）
Normpost-LN，LayerNormpre-LN，RMSNorm（不减 mean，只除以 RMS）
FFNReLU，hidden \(4d\)SwiGLU，3 个矩阵，hidden \(\tfrac23\cdot 4d\)，参数量不变
位置sinusoidal，加在输入RoPE，每层旋转 q、k
AttentionMHAGQA：几个 query head 共享一组 K、V，KV cache 变小

必答点

  • encoder 层：self-attention + FFN；decoder 层多 masked self-attention 和 cross-attention
  • cross-attention：Q 来自 decoder，K、V 来自 encoder 输出
  • 每个 sub-layer：residual + LayerNorm；post-LN 要 warm-up，pre-LN 更稳
  • FFN：position-wise 两层 MLP，hidden \(4d\)；每层参数 ≈ \(12d^2\)
  • 现代 LLM：decoder-only + pre-LN RMSNorm + SwiGLU + RoPE + GQA

追问

为什么 post-LN 需要 warm-up，pre-LN 不需要？

Xiong et al. 证明，post-LN 初始化时最后几层参数的 gradient 期望很大，直接用大 learning rate 会不稳；pre-LN 进入最后那个 LN 的输入随层数 \(L\) 线性变大，gradient 被 \(\sqrt{L}\) 归一化，所以可以去掉 warm-up。

为什么用 LayerNorm 不用 BatchNorm？

文本序列长短不一，batch 统计量不稳；LayerNorm 对每个 token 自己的 \(d\) 维算统计量，train 和 eval 一样。见 BatchNorm vs LayerNorm 速查。

FFN 有什么用？SwiGLU 为什么 hidden 取 \(\tfrac23\cdot 4d\)？

attention 输出是 V 的加权平均，FFN 给每个 token 加非线性变换，占每层约 2/3 的参数。SwiGLU 有 3 个 \(d\times h\) 矩阵，\(h = \tfrac83 d\) 时 \(3dh = 8d^2\)，和 ReLU FFN 参数量相同。

encoder-only、decoder-only、encoder-decoder 分别用在哪？

encoder-only（BERT）双向看全句，做理解、分类。decoder-only（GPT）做生成。encoder-decoder（原版、T5）做翻译、摘要这类 seq2seq。

为什么现在的 LLM 几乎都是 decoder-only？

一个 stack 结构简单，next-token prediction 每个 token 都有 loss，生成时 KV cache 能直接复用。BigScience 的对比实验里，预训练完直接做 zero-shot，causal decoder-only 最好。

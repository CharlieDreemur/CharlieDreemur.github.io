self-attention 为什么要除以 \(\sqrt{d_k}\)？
为什么不除以 \(d_k\)？

英文问法Why do we scale the dot product by 1/√d_k in attention? · What happens if we don't scale? · Why √d_k and not d_k?

考过★ 作者本人微软 AS 电面 · 面经：微软 AS 实习电面问 self-attention（1p3a 1165076）、MAI Senior L63 手写 attention。手写 attention 见 ml-coding。

先弄清楚：每个概念是什么

Attention score \(q\cdot k\)
query 是"我想找什么"，key 是"我这里有什么"，点积就是匹配分，过 softmax 变成权重。像拿搜索关键词去对网页标签，越像分越高。例：\(q = (1, 2)\)，\(k = (3, 1)\)，\(q\cdot k = 5\)。
点积的 variance 随 \(d_k\) 变大
点积是 \(d_k\) 个随机小项相加，像连掷 \(d_k\) 次 ±1 的硬币累加。掷得越多，总和离 0 越远，典型幅度是 \(\sqrt{d_k}\)。例：\(d_k = 1\) 时 std = 1；\(d_k = 64\) 时 std = 8。
Softmax saturation
输入差距一大，softmax 就"赢者通吃"，几乎变成 one-hot。例：softmax(1, −1) = (0.88, 0.12)；softmax(8, −8) ≈ (1, \(1.1\times10^{-7}\))。
Softmax 的 gradient
\(\partial p_i/\partial s_j = p_i(\delta_{ij} - p_j)\)。已经 one-hot 时每一项都 ≈ 0。票数差太多，分数再改一点结果也不变，\(W_Q\)、\(W_K\) 就收不到信号。

30 秒回答

Because the variance of the dot product grows with d_k. If the components of q and k are independent with mean 0 and variance 1, q·k is a sum of d_k such products, so its variance is d_k and its standard deviation is √d_k. With d_k = 64 the scores are about eight times larger, softmax saturates into a near one-hot distribution, and its gradient p_i(δ_ij − p_j) is almost zero, so the query and key projections barely learn. Dividing by √d_k brings the variance back to 1 regardless of d_k. Dividing by d_k would overshoot: the variance becomes 1/d_k and attention becomes nearly uniform.

推导 / 关键公式

variance：为什么是 \(\sqrt{d_k}\)

假设 \(q\)、\(k\) 各分量独立，mean 0、variance 1（原论文 footnote 4）：

\[ \mathrm{Var}(q_i k_i) = \mathbb E[q_i^2]\,\mathbb E[k_i^2] = 1 \] \[ \mathrm{Var}(q\cdot k) = \sum_{i=1}^{d_k}\mathrm{Var}(q_i k_i) = d_k \] \[ \mathrm{Var}\big(q\cdot k/\sqrt{d_k}\big) = 1 \]

为什么 score 大了学不动

\[ \frac{\partial p_i}{\partial s_j} = p_i(\delta_{ij} - p_j) \]

\(p\) 接近 one-hot 时，每个 \(p_i\) 不是 ≈ 0 就是 ≈ 1，这一项都 ≈ 0 → gradient vanishing。

手算例子：\(d_k = 1\) vs \(d_k = 64\)

两个 key，分数分别比平均高、低一个 std。\(d_k = 1\) 时 score 是 (1, −1)；\(d_k = 64\) 时 std = 8，同样的位置变成 (8, −8)：

\(d_k = 64\) 时scoresoftmax\(p_1(1-p_1)\)
不缩放(8, −8)(≈1, \(1.1\times10^{-7}\))\(1.1\times10^{-7}\)：saturate，学不动
除以 \(\sqrt{d_k} = 8\)(1, −1)(0.88, 0.12)0.105：和 \(d_k = 1\) 一样
除以 \(d_k = 64\)(0.125, −0.125)(0.56, 0.44)0.246：接近 uniform，分不出谁重要

必答点

  • 假设 \(q\)、\(k\) 分量独立、mean 0、variance 1 → \(\mathrm{Var}(q\cdot k) = d_k\)
  • \(d_k\) 大 → score 大 → softmax saturate → gradient \(p_i(\delta_{ij}-p_j) \approx 0\)
  • 除以 \(\sqrt{d_k}\)：variance 回到 1，与 \(d_k\) 无关
  • 除以 \(d_k\) 过头：variance 变 \(1/d_k\)，attention 接近 uniform

追问

为什么不除以 \(d_k\)？

variance 变成 \(1/d_k\)。\(d_k = 64\) 时 score 被压到 ±0.125 附近，softmax 接近 uniform，attention 失去区分度。乘以 \(c\) 后 variance 是 \(c^2 d_k\)，要它等于 1 只能取 \(c = 1/\sqrt{d_k}\)。

multi-head 里的 \(d_k\) 指哪个维度？

每个 head 的维度 \(d_{\text{model}}/h\)。原版 512/8 = 64，所以是除以 8，不是 \(\sqrt{512}\)。

训练中 \(q\)、\(k\) 不再是 unit variance 怎么办？

这个假设只在初始化附近大致成立。ViT-22B 在 8B 规模遇到 attention logits 越来越大、attention 变成 one-hot、loss 发散，解决办法是 QK-norm：先对 \(q\)、\(k\) 做 LayerNorm 再点积。

和 softmax temperature 什么关系？

除以 \(\sqrt{d_k}\) 就是 temperature \(T = \sqrt{d_k}\) 的 softmax。\(T\) 越大分布越平，越小越尖。区别是这里 \(T\) 固定，不调。

为什么不用 additive attention？

原论文：\(d_k\) 小时两者差不多，\(d_k\) 大时 additive 比不缩放的 dot-product 好。缩放后 dot-product 能用矩阵乘法实现，更快、更省内存。

先弄清楚：每个概念是什么

Sandbox
一个受限的执行环境，候选代码只能在里面跑。像实验室的通风橱，反应在里面做，出了事也不波及外面。
Container
和宿主共享同一个 kernel 的一组进程。namespace 管它看得见什么，cgroups 管它能用多少 CPU 和 memory。
gVisor
在 user space 实现了一部分 Linux system call（syscall）接口。候选代码的 syscall 先被它拦下来处理，不直接交给宿主 kernel。
MicroVM
用硬件虚拟化起的轻量 VM，有自己的 guest kernel。例：Firecracker 用 KVM 创建 microVM，官网写启动时间低于 125 ms。
Verifier
判定候选代码对不对、快不快的固定代码。agent 改不了它。

30 秒回答

Agent-written code is untrusted, so I run it like a stranger's code. Each candidate gets its own container or microVM, started from the same clean image, with CPU, memory and time limits, no network, and write access only to its workspace. The verifier and the benchmark scripts sit outside that boundary and are read-only, so the agent can't edit what judges it. It only proposes; fixed code decides keep or reject. On GPUs, compilation can go to CPU nodes, but a timed run gets a whole device, for safety and for clean timing. A container shares the host kernel; gVisor or a microVM isolates more strongly.

三种隔离技术

隔离方式和宿主 kernel 的关系隔离强度
Containernamespace 加 cgroups共享宿主 kernel，syscall 直接到宿主最弱
gVisoruser space 里的一层 kernel 拦截 syscall候选代码的 syscall 不直接传给宿主 kernel居中
MicroVM硬件虚拟化，比如 KVM有自己的 guest kernel最强

FlashVector 没写 sandbox 用哪一种。选型时我会看代码的来源。自己团队的 agent 写的 kernel，先用 container 加资源上限。要跑别的租户的代码时，再换 gVisor 或 microVM。

Sandbox 要管住什么

管什么做法
CPU 和 memorycgroups 设上限
时间timeout，到点由外面的进程 kill
网络默认断网
文件只有 workspace 可写；verifier 和 benchmark 脚本只读
状态每份候选代码从同一个 image 启动，不留上一份的状态
GPU测量时独占一张卡；编译放 CPU 节点

GPU 这一行是 CUDA Agent 的做法。它有 128 张 H20 的 sandbox pool，CPU 编译和 GPU 测量分开，测量时资源独占，verify 和 profile 脚本用文件权限保护。独占一张卡既是为了安全，也是为了计时干净（见 kernel benchmark）。agent 钻评测漏洞的真实例子见 reward hacking。

必答点

  • agent 写的代码按 untrusted 处理，每份候选代码一个 sandbox
  • 限 CPU、memory 和时间，默认断网，只有 workspace 可写
  • container 共享宿主 kernel；gVisor 在 user space 拦截 syscall；microVM 有自己的 guest kernel
  • verifier 和 benchmark 脚本在 sandbox 外且只读，agent 只提案
  • GPU 测量时独占一张卡，编译放 CPU 节点
  • FlashVector 只在图里提到 sandbox，没写用什么技术

追问

让 agent 自己写 test 行不行？

不行，它会写出自己能过的 test。KernelFalcon 让 LLM 生成 test harness，原文承认没有对它做防作弊分析（见 reward hacking）。

从后端角度怎么限制 CPU、memory 和网络？（字节原题）

CPU 和 memory 用 cgroups 设上限，时间用 timeout，到点把整个 sandbox kill 掉。网络给 sandbox 一个不通外网的 network namespace。

gVisor 和 Docker container、VM 有什么不同？（科大讯飞原题）

Docker container 的 syscall 直接到宿主 kernel，gVisor 在中间加了一层跑在 user space 的 kernel 来接 syscall。VM 用硬件虚拟化，guest 有完整的 kernel，gVisor 的文档把自己称为第三种做法。

microVM 和普通 VM 有什么区别？

microVM 只模拟很少的设备，所以启动快、开销小。Firecracker 官网写它只有 5 个模拟设备，启动时间低于 125 ms，每个 microVM 的 memory 开销低于 5 MiB。
